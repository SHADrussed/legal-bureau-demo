# Права на ассеты

Все иллюстрации, композиции, логотипы и favicon созданы специально для этого демонстрационного проекта в виде SVG/CSS. Внешние фотографии, портреты, чужие логотипы и изображения с референсов не используются.

Локальный шрифт из npm @fontsource/manrope: SIL Open Font License 1.1, допускает коммерческое использование и распространение с лицензией. Фактически используемые лицензии включены в public/fonts/*-LICENSE.txt. Официальный исходник: https://github.com/sharanda/manrope .

Ссылки на юридические сайты в DESIGN_SPEC служат только исследовательскими референсами. Их ассеты и тексты не скопированы.

`public/social-preview.png` — собственный скриншот первого экрана этого проекта, использованный для Open Graph. Новых сторонних ассетов при публикации не добавлялось.
